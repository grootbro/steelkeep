## This slice

Visual thesis: the same calm operational hierarchy as the reference's server profile—entity heading and actions, a narrow summary strip, working plans and snapshots, public connection facts alongside, recent jobs below. It uses existing Steelkeep surfaces and typography instead of adding a second design language.

Content and interaction: clicking a connection opens a real deep-linked profile with native back navigation. Plan and artifact actions call the existing application callbacks; source holds, permissions, request-key recovery and restore acknowledgement stay in force. A source, storage and restore destination each show relevant data, with correct empty states. Passwords, access keys and arbitrary config JSON are never rendered.

The profile's lists use current overview/jobs DTOs and remain explicitly bounded to the latest 100 records. The new summary endpoint separately supplies all recorded history aggregates when the server advertises support; older-server fallback stays labeled as recent. Aggregate counts do not imply physical capacity or downloaded-byte integrity checks.
