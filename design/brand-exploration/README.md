## Round 01 — rejected

Exploration only. No live application brand assets were changed.

The generated contact sheet is `steelkeep-logo-directions-contact-sheet.png`.
It was produced with the built-in image generation tool from the complete prompt
saved in `imagegen-prompt.txt`. It is a raster moodboard, not vector production art.

The `*-symbol-*.svg` files are separately authored original editable vector
interpretations of those four directions. They are deliberately not described as
automatically traced or pixel-identical to the generated concepts. Each includes
color, one-color and inverse variants. `steelkeep-vector-directions.svg` groups them.

1. **Fold** — a compact folded S, the most direct connection between “steel” and
   continuity. Strong first candidate for an app icon; accent plane needs careful
   simplification at 16px. Slightly industrial, confident, clear.
2. **Keeper** — an open arch with a protected square. Softer and approachable;
   more literal sense of a safe place, but can read as a home/property product.
3. **Checkpoint** — offset versions stepping forward. The most product-specific
   backup/versioning idea, distinctive silhouette and calm operational character.
   Main recommendation alongside Fold.
4. **Monogram** — custom sk. Compact and ownable as a typographic direction;
   more complex silhouette needs optical cleanup before a tiny favicon is final.

For the name, prefer **Steelkeep** in title case, with gentle kerning and a single
weight; “Steel Keep” looks more architectural and long all-caps feels heavier.
The fourth direction can explore a subtle weight emphasis on “keep” without a
color split. Avoid making “Steel” thin or aggressively industrial.

The editable lockups use `Instrument Sans` with system fallbacks. Letter outlines
are not frozen; the final selected lockup must be outlined or use the product's
self-hosted font consistently before distribution. The symbol SVGs have no font
dependency and can inherit colors by editing their root CSS custom property.

Recommended next selection: compare **01 Fold** and **03 Checkpoint** at 16px,
24px, sidebar wordmark scale and monochrome, then refine just one. The current
files are design candidates, not a trademark-clearance or uniqueness claim.

No browser, application, container, build, lint, typecheck or tests were run.
The generated contact sheet was visually inspected in the image tool output;
the SVG files were source-inspected only and still need optical/rendered review.
